# Panel methodology

The methodology note that ships with the data is the canonical one. It
lives at `data/processed/README_PANELS.txt` and is mirrored into the
shared Dropbox folder at the top level, next to the panels themselves.

It covers every file we deliver: the detention, encounters, and stays
panels, the combined 2012-2026 series, the county population measures,
the balanced county-month panel, the enforcement spike and
intermittency measures, and the area-of-responsibility exposure work.

This file used to hold a second copy of that note. Keeping two copies
meant they drifted apart, so this one now points at the original
instead.
